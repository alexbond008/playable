# Playable

**Drop in any STEM course material. Get a 3D game that teaches it.**

Playable is an agent skill for Claude Code, Codex, Antigravity and OpenCode. Give it a lecture PDF, a tutorial sheet, a coursework docx or a whole lab folder, and it builds a game you can play in the browser: real physics, sound, haptics and learning science, with every number checked against your source.

> Status: in development. Nothing to install yet.
